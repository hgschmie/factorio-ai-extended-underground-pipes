# Extended Underground Pipes

## Before you install this mod

This was intended as a joke, based on a discussion on the Factorio Forums where people were complaining that "underground pipes reach just one tile short" while at the same time other (the same?) people were complaining about AI Slop.

It is one-shot, vibe-coded by running a single prompt into Claude (Opus 4.6 or so): `Create a factorio mod that extends the reach of underground pipes by one tile`.

The only thing that I verified is that the mod loads, then I released it and pushed it to github. Heck, I did not even add a footer or any documentation to it.

... and I got a request to update if to Factorio 2.1 because people actually have installed it (awesome, who would have thought)...

So there: Second prompt: `this folder contains a factorio mod. Update it to factorio 2.1 compatibility, change the version to 2.0.0, add a changelog entry and commit the changes`. This time with GPT-6 Astra. It did it flawlessly.

## Description

A Factorio mod that extends the maximum distance of underground pipes by 1 tile.

### What it does

- Increases the maximum underground distance for pipe-to-ground entities by 1 tile
- Default underground pipe distance is 10 tiles, this mod makes it 11 tiles

### Compatibility

- Factorio version: 2.1
- Dependencies: base mod only
- Should be compatible with most other mods
